# Privacy and testing / 隐私与测试

## Public data classes / 公开数据分类

- **Public reference information**: official dependency and license links only.
- **Synthetic data**: fixed-seed workbooks and UI previews created specifically for this repository.
- **Real or internal data**: explicitly excluded from the repository and from its Git history.

公开仓库只包含官方依赖链接和固定种子仿真数据。任何真实或疑似内部工作簿、模板、输出、报告、规则、图片和截图都不属于公开范围。

## Synthetic workbook provenance / 仿真工作簿来源

The three workbooks under `samples/simulated/` and the template under `assets/` were generated from scratch with seed `20260827`. Names, identifiers, dimensions, weights, materials, processes, images, and worksheet titles are fictional. Media files are deterministic colored patterns generated by code.

See `samples/simulated/manifest.json` for the feature matrix and file hashes.

## XLSX audit / XLSX 审计

`tools/audit_public_repo.py` inspects every allowed workbook as an OOXML ZIP package and checks:

- explicit XLSX allowlist;
- visible/hidden worksheet states;
- comments and threaded comments;
- external links and external relationships;
- custom XML and VBA/macro parts;
- document XML for local paths, excluded identifiers, and credential-like text;
- media count and SHA-256 inventory;
- large files and unexpected binary types.

It also scans all repository text files for local absolute paths, attachment identifiers, common secret formats, excluded profile identifiers, and organization/user tokens.

## Public test scope / 公开测试范围

The `unittest` suite uses only repository fixtures and system temporary directories. It covers:

- single, multi-row, bilingual, merged, XYZ, and low-information headers;
- A/Z/AA/AB column labels and the horizontal mapping contract;
- multi-sheet recommendations and independent outputs;
- name composition, blank cleanup, deduplication, and multiplication-sign preservation;
- weight/length/area conversions and dimension parsing;
- L1–L13 level groups plus multiple/missing-marker warnings;
- local rule persistence without row examples;
- quick and confirmed conversion;
- byte-preserving image copy;
- row-5 storage-style reuse and 12 generic template formulas;
- Markup Compatibility namespace and calculation-chain checks;
- new-task reset contract.

Synthetic regression tests are necessary but insufficient. A user must still perform local acceptance tests with workbooks and templates they are authorized to process, especially for ambiguous mappings and Microsoft Excel behavior.

## Screenshot safety / 截图安全

Committed screenshots contain only the built-in fictional preview state. The mapping-matrix illustration is a hand-authored SVG with no embedded raster image, external resource, font file, metadata payload, or personal path.

## Release gate / 发布门槛

Before every push:

1. run all public tests;
2. run the repository audit;
3. inspect `git status` and the complete tracked-file list;
4. verify that only the four explicitly allowed `.xlsx` files and sanitized UI images are present;
5. stop if any violation, failed test, uncertain license, or uncertain data provenance is found.
