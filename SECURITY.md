# Security and privacy reports

This repository is designed for offline processing. Please do not attach real workbooks, templates, local reports, mapping-rule databases, screenshots, credentials, or organization-specific data to a public issue.

If a potential privacy leak is found, keep the affected file local, record only a minimal technical description, and contact the repository owner through a private channel available on their GitHub profile. Do not post the sensitive file itself.

The public repository intentionally contains no network upload integration and no secret-management mechanism because workbook data is not expected to leave the local machine.
